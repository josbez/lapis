# Lapis

Een rustige markdown-editor voor een map met `.md`-bestanden op je Mac.

Lapis doet wat Obsidian doet op de dag dat je gewoon wilt schrijven en terugvinden —
en verder niets. Geen graph view, geen plugin-store, geen ribbon met twaalf iconen.
Je bestanden blijven gewone markdown in een gewone map.

**Status:** discovery. Er is nog geen code. Dit is een productdossier.

## De kern in vier regels

1. Wijs Lapis naar een map. Dat is de hele configuratie.
2. Je ziet je tekst, opgemaakt, terwijl je typt. Eén venster.
3. `⌘K` om iets te openen, `⌘⇧F` om iets te vinden. Dat zijn de belangrijkste knoppen.
4. Lapis schrijft niets in jouw map dat geen markdown is.

## Uitgangspunten

- **Lokaal-eerst.** Geen account, geen cloud, geen telemetrie.
- **Jouw bestanden blijven van jou.** Als Lapis morgen verdwijnt, verlies je niets.
- **Weglaten is een feature.** Elk scherm-element moet zich verantwoorden.
- **Naast Obsidian, niet in plaats van.** Dezelfde map moet in beide werken.
